# 数学公式 → 中文朗读：受限语法与发音词典

两套不同的数据：`display_math` 是纯数学表达式；`spoken_text` 是教师真实朗读稿。`normalize_math` 仅用于提示，不可替代数学语义验证。

## 默认支持

- `+ - = * / < >`，负数、有限小数、0–999 的整数读法。
- `x^2` / `x^3` / `x^{n}`，`F_1`，`\frac{a}{b}`，`\sqrt{x}`。
- `\alpha`、`\beta`、`\theta`、`\pi` 及常见正弦余弦。

## 明确拒绝

- 未注册 LaTeX 命令、矩阵环境、复杂嵌套语法、歧义字符、超出支持范围的数值。
- 带变量域和条件的数学结论没有经教师语义审查就作为旁白发表。

### 典型对照

| 数学 | 自动提议 | 建议教师正式口播 |
|---|---|---|
| `a^2+b^2=c^2` | a 的平方加 b 的平方等于 c 的平方 | 直角三角形两条直角边的平方和，等于斜边的平方 |
| `\frac{x^2}{16}+\frac{y^2}{9}=1` | （x 的平方）除以（十六）加（y 的平方）除以（九）等于一 | 横坐标的平方除以十六，加上纵坐标的平方除以九，等于一 |
| `F_1` | F 下标一 | 焦点一 |

适配 eSpeak 的数学词典建议增加按年级的 `terms.json`，带 `canonical`、`spoken`、`ambiguous_context`、`human_review` 四列。**不能**仅通过字符串替换把严谨数学叙述硬改为短语。
